## 프로젝트 지도 — 초기 템플릿

- 프로젝트 언어와 실행 진입점을 현재 파일 목록에서 확인한다.
- 화면 → API → 서비스 → 데이터 접근 → 테스트의 위치를 20줄 안팎으로 기록한다.
- 특정 언어나 서버 구조를 가정하지 않는다. 해당 계층이 없으면 생략한다.
- 프로젝트별 공통코드·상수·주석에서 용어 사전 초안을 작성하고 근거 path/line을 붙인다.
- 용어 사전: install/knowledge/glossary.json. 검토 전 항목은 reviewed=false로 둔다.
- 생성물·접속 정보의 보호 패턴은 install/config.json에서 추가한다.
