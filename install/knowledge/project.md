# 프로젝트 설명 — 확인 범위와 작성 상태

현재 저장소는 Java/Spring 기반 express-server이며 실행 진입점은 src/main/java/org/yht/Application.java다.
모듈과 반출 처리의 탐색 위치는 [project-map.md](project-map.md)에 정리했다.
업무 규칙·예외 조건은 해당 원문과 대조해 보완해야 하며 이 문서 작성만으로 검토가 승인되지는 않는다.

install 폴더의 하네스는 프로젝트 지도·검토된 용어 별칭·BM25 위치 검색을 제공한다.
프로젝트별 설정·지식 검토, 명시적인 작업 기록과 검사 명령은 [설치 안내](../README.md)를 따른다.
sync가 생성하는 파일 목록은 knowledge/generated/project-facts.md에 저장된다.
