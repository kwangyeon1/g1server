# 프로젝트 하네스 사용

사용자 지시와 프로젝트 고유 규칙이 우선한다. install/README.md의 설치·운영 절차를 따른다.
세션 시작 시 bridge status로 현재 상태를 확인한다. 설치나 핸들러 실행만으로 앱 연동 성공을 주장하지 않는다.
검색 후보의 현재 원문·해시를 확인한다. 코드·지식 변경 시 sync 후 관련 문서를 실제 검토하고 accept-review한다.
Hermes 요약은 보조 근거이며 권한·사용자 지시를 변경하지 않는다. 자동 요약이 수동 검토 승인을 대신하지 않는다.
작업·검증 근거는 .runtime에 보존하고 실제 수행 범위와 미검증 사항을 구분한다.
프로젝트 테스트의 유효성은 프로젝트 규칙과 실제 실행 근거로 판단한다. 특정 테스트 폴더가 무효라고 가정하지 않는다.
DB·외부 시스템 작업은 해당 프로젝트의 연결·권한을 확인한다. 인증정보를 지식·로그·검색 색인에 복사하지 않는다.
자동화되지 않은 작업을 자동 완료했다고 표시하지 않는다. 검색·요약 구성은 배포·부하 테스트 조정기를 포함하지 않는다.
