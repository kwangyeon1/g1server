# 프로젝트 하네스 사용

사용자 지시와 프로젝트 고유 규칙이 우선한다. install/README.md의 설치·운영 절차를 따른다.
설치나 핸들러 실행만으로 앱 연동 성공을 주장하지 않는다.
기본 탐색은 grep/원문 읽기이며, 식별자를 모를 때만 locate로 위치 후보를 찾는다. 코드·지식 변경 시 sync 후 관련 문서를 실제 검토하고 accept-review한다.
작업·검증 근거는 .runtime에 보존하고 실제 수행 범위와 미검증 사항을 구분한다.
프로젝트 테스트의 유효성은 프로젝트 규칙과 실제 실행 근거로 판단한다. 특정 테스트 폴더가 무효라고 가정하지 않는다.
DB·외부 시스템 작업은 해당 프로젝트의 연결·권한을 확인한다. 인증정보를 지식·로그·검색 색인에 복사하지 않는다.
작업 기록·검토·테스트는 실제 수행한 범위를 명시한다. 배포 ZIP 생성은 하네스 설치 파일의 패키징이다.

요청 훅은 검토된 용어 매칭만 수행한다. 검색 결과의 선주입을 추가하지 않는다.
검색 엔진은 navigation.py 하나로 유지한다. MCP는 locate 도구 하나만 노출한다.
배포 기본값에는 프로젝트 고유 지식·사용자 경로·승인 상태를 포함하지 않는다.
